# 联合改稿工作台

面向公关团队的三方联合改稿工具：品牌与法务在同一份底稿上各自修改后，系统按段落做三方合并，自动吸收互不冲突的修改，把真正需要人决定的冲突逐条呈现出来处理。所有数据仅保存在浏览器本地（localStorage），不经过任何服务器。

技术栈：React 18 + TypeScript + Vite，测试用 Vitest + Testing Library。

## 运行方式

```bash
npm install        # 安装依赖
npm run dev        # 开发模式（默认 http://localhost:5173）
npm test           # 运行全部测试（50 个用例）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 本地预览生产构建
```

## 功能

- **四栏并排**：共同底稿 / 品牌版 / 法务版 / 合并结果，逐段对照。
- **三方段落合并**（`src/lib/merge.ts`）：
  - 只有一方修改（或双方改得一样）→ 自动采用；
  - 双方改了同一段且结果不同 → `edit-edit` 冲突；
  - 一方删除、另一方修改 → `delete-edit` 冲突；一方删除、另一方移动 → `delete-move` 冲突；
  - 双方把同一段移到不同位置 → `move-move` 冲突；
  - **一方移动、另一方只改内容 → 自动合并：保留新位置，同时采用新内容**，不会误判成"删除 + 新增"。
- **移动识别**（`src/lib/align.ts`）：LCS 锚点 + 词级相似度贪心配对 + 最长递增子序列（LIS）判定相对顺序，被移动的段落带 `⇄ 移动` 徽章并标注来源位置。
- **冲突处理**：工具栏/左侧列表逐个跳转冲突；每处冲突可选 **采用品牌版 / 采用法务版 / 保留底稿 / 手动填写**；已解决的可以"重新打开"。
- **撤销 / 重做**：`Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`（或 `Ctrl+Y`），覆盖所有裁决操作与"恢复示例"。
- **一键恢复示例**：内置一份联合发布稿，覆盖互不冲突修改、同段冲突、删除与编辑冲突、双方插入、段落移动+改写等全部场景。
- **可编辑原稿**：三栏原稿均可直接编辑（空行分段），保存后立即重新合并。
- **可读性**：段落内做词级 diff（中文按字、英文按词），删除用删除线、新增用下划线，配合图标+文字徽章，不依赖颜色传达信息；点击合并结果中的段落可在两侧原稿中高亮定位。
- **导出**：一键复制 / 下载合并稿（未解决冲突会以标记行注明并暂留底稿原文）。

## 合并算法说明

1. **对齐**（每个修订版 vs 底稿）：先用 LCS 匹配内容完全一致的段落作为锚点；未匹配段落按词级相似度（Dice 系数）贪心配对——同一"空隙"内阈值较低（视为原地改写），跨空隙阈值较高（视为移动）；最后用 LIS 找出保持相对顺序的最大配对集合，集合之外的配对即为移动段落，其余未配对的分别是删除与新增。
2. **裁决**（对底稿每一段）：分别在"存在性 / 位置 / 内容"三个维度比较三方——双方都删则删；一方删、另一方动过（改或移）则冲突；移动目标唯一则采用新位置；内容按"两方一致用一致值、否则用改动方"自动合并，双方都改且不同则冲突。
3. **组装**：原地段落占据底稿槽位，移动/新增段落挂在锚点槽位之后排序输出；双方在同位置插入相同内容时去重。

## 项目结构

```
src/
  lib/
    text.ts        分词（中文按字/英文按词）、归一化、段落切分
    lcs.ts         LCS / LIS 序列算法
    similarity.ts  段落相似度
    align.ts       底稿↔修订版段落对齐（含移动识别）
    diff.ts        词级 diff（界面高亮用）
    merge.ts       三方合并、冲突分类、裁决应用、导出
    *.test.ts      合并 / 移动识别 / 人工解决 测试
  state/
    history.ts     撤销/重做历史栈（纯函数）
    useWorkbench.ts 工作台状态 + localStorage 持久化
    history.test.ts
  components/      工具栏、统计栏、冲突侧栏、原稿栏、合并栏、冲突卡片等
  sample.ts        内置联合发布稿示例
  sample.test.ts   示例稿件端到端校验
  app.test.tsx     界面冒烟测试（解决/撤销/重做/恢复/持久化）
```

## 测试

`npm test` 运行 50 个用例，覆盖：

- 三方合并基本规则（单方修改、双方同改、插入、删除、去重）
- 移动识别（单方移动、移动+他方改写、双方同位移动、移动分歧、移动 vs 删除）
- 冲突分类（edit-edit / delete-edit / delete-move / move-move）
- 人工解决（四种裁决方式、重新打开、导出标记）
- 撤销 / 重做历史栈
- 内置示例的端到端合并结果
- 界面冒烟（渲染示例、解决冲突、撤销重做、恢复示例、localStorage 持久化）
